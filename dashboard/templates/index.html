Kafka Streaming Layer

Daily NAV ticks & Benchmark indices are published to Kafka topic mutual_fund_daily_nav. Keyed by Scheme to guarantee sequential delivery of daily time-series records per fund.

producer.send('mutual_fund_daily_nav', key=scheme, value=nav_record)
2

Hadoop HDFS Lake

A Kafka consumer ingests streamed ticks and writes them into time-partitioned HDFS directories /user/bda/mutual_funds/nav_data/year=YYYY/month=MM/ for distributed Big Data storage.

/user/bda/mutual_funds/nav_data/year=2026/month=08/nav_data_2026_08.csv
3

Hadoop Map Phase

mapper.py reads partitioned CSV files across cluster nodes via STDIN. Emits key Scheme and value Date,NAV,Benchmark,BenchmarkVal,Category to feed the shuffle & sort phase.

sys.stdout.write(f"{scheme}\t{date},{nav},{bench},{bval},{cat}\n")
4

Hadoop Reduce Phase

reducer.py aggregates all chronological dates per scheme. Executes rolling window calculations for 30/60/90-day returns, benchmark alphas, beta, and annualized volatility metrics.

Alpha_90 = Ret_Fund_90d - Ret_Bench_90d Beta = Cov(R_fund, R_bench) / Var(R_bench)

Hadoop Cluster Deployment Command

To run on a distributed Apache Hadoop cluster with YARN, use Hadoop Streaming:

hadoop jar $HADOOP_HOME/share/hadoop/tools/lib/hadoop-streaming-3.3.6.jar \
  -D mapreduce.job.name="MutualFund_Rolling_Returns" \
  -D mapreduce.job.reduces=4 \
  -files mapper.py,reducer.py \
  -mapper "python3 mapper.py" \
  -reducer "python3 reducer.py" \
  -input "/user/bda/mutual_funds/nav_data/*" \
  -output "/user/bda/mutual_funds/output"
Data as of: — NAV & benchmark time-series are simulated (seeded random walk) around the Kaggle Mutual Funds India snapshot — scheme, category, benchmark, expense ratio and 1-yr CAGR are real.
